# NELS ComfyUI Plugin

ComfyUI plugin for building CLIP-encoded prompt datasets, loading them into an interactive
graph panel, and running latent-space navigation/exploration operations directly
on the graph. Operation results route back into a normal ComfyUI generation graph,
so a trajectory through the dataset becomes a batch of viewable, generated images.

---

> Dataset creation is available two ways: **ComfyUI nodes** (desktop) or a **standalone CLI**
> (server/headless) - see [scripts/ENCODE_CLI.md](scripts/ENCODE_CLI.md) for the CLI.

## Nodes

### Dataset creation

| Node                     | Purpose                                         |
| ------------------------ | ----------------------------------------------- |
| `NELS Prompt Encoder`    | Encode text prompts via CLIP into a new dataset |
| `NELS Add to Dataset`    | Append new prompts to an existing dataset       |
| `NELS Dataset Annotator` | Generate LLM cluster labels for a dataset       |

### Graph exploration

| Node                        | Purpose                                                  |
| --------------------------- | -------------------------------------------------------- |
| `NELS Dataset Loader`       | Load a saved dataset into the session pipeline           |
| `NELS Session`              | Build a session bundle from loaded data + panel UI state |
| `NELS Graph Operation`      | Run a graph operation and produce a trajectory           |
| `NELS Graph Panel Launcher` | Open / focus the NELS Graph bottom panel                 |

### Result routing

| Node                             | Purpose                                                  |
| -------------------------------- | -------------------------------------------------------- |
| `NELS Prompt Conditioning Batch` | Turn a trajectory into `CONDITIONING` for KSampler       |
| `NELS Comparison Grid`           | Arrange generated `IMAGE` batches into a comparison grid |
| `NELS Save Run Bundle`           | Save trajectory images + metadata to disk                |

## Getting started

1. Drop (or symlink) this folder into `ComfyUI/custom_nodes/` or clone the plugin branch directly into `ComfyUI/custom_nodes/`:

   ```bash
   cd ComfyUI/custom_nodes
   git clone --branch plugin https://github.com/davidg-h/NeLs.git
   ```

2. `pip install -r requirements.txt`
3. `npm install && npm run build` - builds the graph panel bundle into `js/`
4. Restart ComfyUI, then load [`examples/workflows/nels.json`](examples/workflows/nels.json) - example workflow where
   dataset creation, graph exploration, and the KSampler round-trip are already wired together

> Step 3 is only needed if you want to modify the graph panel UI. The prebuilt bundle is already included in the repo.

## Dataset creation: nodes vs CLI

### Prompt dataset (nodes)

1. Add **Load CLIP** → connect to **NELS Prompt Encoder**
2. Set `input_source` to `file` (point `file_path` at a `.txt` file) or `huggingface`
3. Optionally type extra prompts directly in the `prompt_text` box - these are prepended and count toward `encode_limit`
4. Set `encode_limit` (0 = all) and `save_path`
5. Queue - dataset folder is created at `save_path/<dataset_name>/`

### Adding prompts (nodes)

1. Add **NELS Add to Dataset**, set `dataset_path` to an existing dataset folder
2. Connect the **same CLIP** that was used to create the dataset
3. `prompt_text` fills first, then `file_path` fills remaining capacity up to `encode_limit`
4. Queue - new samples are appended, and the cluster + 2D/3D UMAP projections and HDBSCAN
   clustering are fully refit on the merged dataset (old + new samples together), not just
   projected through the old models - see [scripts/ENCODE_CLI.md](scripts/ENCODE_CLI.md#cluster-relabeling-on-add)

### CLI

See [scripts/ENCODE_CLI.md](scripts/ENCODE_CLI.md) for the full reference (installation,
subcommands, output format, examples). Example usage:

```bash
python scripts/encode_cli.py create \
  --clip models/text_encoders/qwen_3_4b_fp4_flux2.safetensors \
  --clip-type FLUX2 \
  --input prompts.txt \
  --encode-limit 1000 \
  --output datasets/my_prompts
```

## Cross-compatibility

| Created by | Add via CLI                                                        | Add via node            |
| ---------- | ------------------------------------------------------------------ | ----------------------- |
| CLI        | Auto (reads the dataset's recorded `encoder` + `clip_type` fields) | Connect same CLIP model |
| Node       | Explicit `--clip` required                                         | Connect same CLIP model |

---

## Notes

- **UMAP and HDBSCAN run on CPU** (`umap-learn`, Parametric UMAP's TensorFlow backend forced
  CPU-only). Encoding runs on GPU via ComfyUI model management.
- **`encode_limit`** applies to the combined total of inline text + file/HF source in the Prompt Encoder.
